> 核查日期：2026-08-11 ｜ 核查范围：api_md_staging/ 全部接口文档的 setup 步骤
> 判定标准：API 无独立接口文档 + URL 前缀不在 RCC-Space 工程（/rcc/、/space/、/spacetci/）

## 外部接口总览

| # | API | 引用文档数 | 类型 | 处理方式 |
|---|---|---|---|---|
| 1 | `POST /rco/admin/loginAdmin` | 211 | 平台级公共登录 | **框架内置**（见 SETUP_PARAM_SPEC.md §11 登录约定） |

## 1. POST /rco/admin/loginAdmin（已内置）

- **位置**：211 个接口文档的 setup 第一步
- **类型**：平台级公共登录（RCC-Space 工程外，所有子模块共用）
- **处理**：✅ 已按方案 2 内置——引擎遇到此 API 不查文档，用环境配置（ADMIN_USER/ADMIN_PASSWORD）登录，token 注入 `${context.token}`，401 自动重登
- **详见**：SETUP_PARAM_SPEC.md §11 登录约定

## 2. POST /rco/admin/list（待处理）

- **位置**：`rcc_admin_dataPermission_query.md`（setup 步骤 `listAdmin`）
- **用途**：查询管理员 ID（`extract: adminId = $.content.itemArr[0].id`）
- **类型**：平台级管理员查询（出参 DTO 在外部模块，jsonpath 标注"待验证"）
- **现状**：文档含 extract（`$.content.itemArr[0].id`），但出参结构无法从 RCC-Space 源码验证
- **建议**：与 loginAdmin 同属 rco 平台接口，二选一：
  - **A（推荐）**：框架内置 `admin/list` 查询（返回 adminId 列表），引擎配置 token 路径即可
  - **B**：保持文档 extract，运行时由引擎验证/校正 jsonpath

## 3. file:///config/packet/{rpmName}.ini（本地文件）

- **位置**：`rcc_classroom_cmr_version_getRpmAndSubsystemVersion.md`
- **用途**：读取 CMR 包配置（rpmName 参数化）
- **类型**：本地文件读取，非 HTTP 接口
- **处理**：引擎遇到 `file://` 前缀的 setup api → 直读本地文件（路径含 `${param.*}` 则先替换参数），不发起 HTTP

## 4-5. https://{cluster_virtual_ip}:9274/api（直连集群）

- **位置**：`rcc_classroom_cmr_download_getUrl.md`（setup 步骤 `up_1`/`up_2`）
- **用途**：直连集群虚拟 IP 的 CMR 下载接口（getBtU/getIns），非经 RCC-Space 网关
- **类型**：外部直连 API（cluster_virtual_ip 由环境配置提供）
- **处理**：引擎遇到 `https://` 开头且非 RCC-Space 网关的 api → 用环境配置的集群地址（`${context.cluster_virtual_ip}`）替换后直连；鉴权按该接口自身要求

## 引擎处理规则（补充 SETUP_PARAM_SPEC.md）

引擎执行 setup 步骤时，按 API 前缀分流：

| API 前缀 | 处理 |
|---|---|
| `POST /rco/admin/loginAdmin` | 内置登录（§11） |
| `POST /rco/admin/list` | 内置管理员查询（或按文档 extract） |
| `file://` | 本地文件读取（路径先替换 `${param.*}`） |
| `https://{cluster_virtual_ip}:9274` | 直连集群（地址由环境配置注入） |
| `/rcc/` `/space/` `/spacetci/` | 正常走接口文档（setup 过滤参数 + extract） |

## 核查结论

- RCC-Space 工程 setup 引用 **37 个工程内接口**（/rcc/、/space/、/spacetci/），全部有独立文档 ✅
- **5 个外部接口**：1 个已内置（loginAdmin）、1 个待定（admin/list）、3 个非 HTTP/直连（file://、集群直连）
- 外部接口出参 DTO 在平台 jar（RCC-Space 源码不可见），文档用"⚠️ jsonpath 待验证"标注，引擎侧运行时验证
