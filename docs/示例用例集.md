# 示例用例集（可直接复制到平台执行）

> 每个用例：结构化模板 + 参数 JSON。复制到「用例输入」页执行。
> ⚠️ 执行前确保 BASE_URL 指向真实测试环境（参数中的资源名需环境已有或自动创建）。

## 用例 1：创建教室 + 创建 VDI 策略 + 修改教师机镜像策略

**用例模板**
```text
【前置】
1. 创建教室（教室名=${param.classroom_name}）
2. 创建 VDI 策略（策略名=${param.strategy_name}；CPU、内存、系统盘与镜像A配置不同）

【操作】
1. 修改教师机课程镜像的云桌面策略为 ${param.strategy_name}

【预期】
1. 操作成功：$.status=="SUCCESS"
```

**参数 JSON**
```json
{
  "classroom_name": "test_001",
  "strategy_name": "test_001_strategy",
  "student_image_name": "WIN10_VDI",
  "cpu": 4,
  "memory": 8192,
  "systemSize": 80,
  "teacherIp": "10.10.10.10",
  "admin_user": "admin",
  "admin_password": "admin123"
}
```

## 用例 5：学生机镜像分配（VDI 域）

**用例模板**
```text
【前置】
1. 创建教室（教室名=${param.classroom_name}）
2. 分配 VDI 镜像（镜像=${param.student_image_name}）到学生终端

【操作】
1. 查看学生镜像列表

【预期】
1. 操作成功：$.status=="SUCCESS"
```

**参数 JSON**
```json
{
  "classroom_name": "test_005",
  "student_image_name": "WIN10_VDI",
  "admin_user": "admin",
  "admin_password": "admin123"
}
```

> 说明：镜像分配需环境预置集群/平台/存储池（接口文档 setup 有 get_cluster/get_storage_pool/get_network 查询步骤）。

## 执行建议

1. 从「用例输入」页逐个复制模板 + 参数
2. 先点「预览计划」确认编排步骤正确（dry-run）
3. 再点「执行用例」，到「执行过程」页看实时日志
4. 参数中的 `admin_user`/`admin_password` 用真实环境凭据
