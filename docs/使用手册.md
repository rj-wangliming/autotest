# 无封装测试平台 使用手册

> 版本：v1.0（2026-08）
> 平台地址：http://127.0.0.1:5001（启动 `python3 run.py`）

## 一、快速上手（3 步）

1. **启动**：`cd /Users/swlim/Desktop/ruijie/autotest && python3 run.py`
2. **浏览器打开** `http://127.0.0.1:5001`
3. **输入用例**：进入「用例输入」页 → 粘贴结构化用例 → 配置参数 → 「预览计划」→「执行用例」

## 二、4 个可视化页面

| 页面 | 路由 | 功能 |
|---|---|---|
| 首页 | `/` | 平台总览 + 接口统计 |
| 用例输入 | `/use-case` | 结构化用例模板 + 参数配置 + dry-run 预览 + 执行 |
| 接口列表 | `/apis` | 224 接口检索 + 详情（入参/出参/断言/轮询） |
| 执行过程 | `/execution` | 用例执行实时日志 + 步骤结果 + 生成脚本 |
| 模型配置 | `/model` | LLM 配置（自由文本用例解析用） |

## 三、用例输入规范（结构化模板）

用例按三段写，每段内"动作 + 实体 + 约束"短句分行：

```text
【前置】
1. 创建教室（教室名=${param.classroom_name}）
2. 创建 VDI 策略（策略名=${param.strategy_name}；CPU、内存、系统盘与镜像A不同）
3. 分配 VDI 镜像（镜像=${param.student_image_name}）到教师终端

【操作】
1. 修改教师机课程镜像的云桌面策略为 ${param.strategy_name}

【预期】
1. 操作成功：$.status=="SUCCESS"
```

### 参数引用语法

| 语法 | 含义 | 示例 |
|---|---|---|
| `${param.xxx}` | 用例输入参数（在"参数 JSON"里提供） | `${param.classroom_name}` |
| `${prev.X}` | 前置步骤产出变量（extract 自动注入） | `${prev.classroomId}` |
| `${context.xxx}` | 全局上下文（如 token） | `${context.token}` |

### 支持的动作词

| 动作 | 匹配接口 | 示例 |
|---|---|---|
| 创建 | `*/create` / `*/add` | 创建教室、创建策略、创建座位 |
| 分配 | `*/assign*` | 分配镜像 |
| 修改/变更 | `*/edit` | 修改策略 |
| 删除 | `*/delete` | 删除教室 |
| 关机 | `*/shutdown` | 关闭桌面 |
| 重启 | `*/restart` | 重启终端 |
| 查看/查询 | `*/list` | 查看桌面列表 |

## 四、参数配置

「用例参数（JSON）」填入用例用到的参数：

```json
{
  "classroom_name": "test_001",
  "student_image_name": "WIN10_VDI",
  "strategy_name": "test_001_strategy",
  "cpu": 4,
  "memory": 8192,
  "systemSize": 80,
  "admin_user": "admin",
  "admin_password": "admin123"
}
```

- `admin_user`/`admin_password`：登录凭据（框架内置 loginAdmin 用）
- 必填字段若缺省，脚本会用 `_ctx.get()` 返回 None（请求体含 null 字段，需提供真实值）

## 五、执行过程理解

「执行过程」页展示：
- **实时日志**：`[req]`（请求）/`[resp]`（响应）/`[poll]`（轮询）/`[extract]`（提取）/`[error]`（错误）分级着色
- **生成脚本**：本次用例的裸 Python 脚本（可独立运行）
- **执行结果**：PASS/FAIL + 各步骤状态

### 异步轮询
接口返回 `BatchTaskSubmitResult` 时，脚本自动按接口文档的 polling 配置轮询 `content.taskId` 至终态（SUCCESS/FAILURE）。

### 幂等与清理
- 创建步骤 `idempotent: recreate`：存在同名先调 delete_api 删除再创建
- 用例结束 finally 逆序清理已创建资源（classroom/strategy/vdi）

### 登录与会话
- 首个步骤若为 `POST /rco/admin/loginAdmin` → 框架内置登录（token 注入后续请求）
- 401 自动重登一次再重试

## 六、模型配置（可选）

自由文本用例（非结构化模板）解析需要 LLM。结构化模板（【前置】【操作】【预期】）**0 AI**，无需配置模型。

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 端口 5000 被占 | 平台用 5001（macOS AirPlay 占用 5000） |
| 接口文档找不到 | 设环境变量 `API_MD_DIR` 指向 api_md 目录，或放平台同级 `api_md/` |
| 执行 FAIL（连接失败） | 检查「目标环境」BASE_URL 是否可达 |
| 参数缺省 | 请求体含 null 字段 → 在参数 JSON 补齐必填参数 |
